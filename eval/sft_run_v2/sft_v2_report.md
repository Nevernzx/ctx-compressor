## 留出集和生成协议

同一批训练留出题组合成 n=249 个任务，保存的检索步数 n=2,326。两种模式乘三档预算得到每个 checkpoint 的 n=1,494 条轨迹，共 n=13,956 个动作。任务05的留出输入 SHA-256 为 `5a6c8ce2c2c738ff2a0e3a15e95d43e8b6ecde7806d7104e5472cf74dddaafac`。从 v1、v2 两份轨迹提取的任务、问题和检索序列有相同的 SHA-256 `07fa05e04b1ea89b0e352d607e76eb9045bba2459b6b7e8316575de2eb7f2512`。

首步用户文本逐字节、提示 token ID 逐项一致（每个 checkpoint n=1,494）。沿用任务05的 vLLM 原生 LoRA 加载、贪心解码和每步 256 个输出 token 上限。依次判定 JSON、候选编号、只追加模式删除和超预算错误；遇到任一错误，本步保留区不变。基础模型与规则策略均来自任务05保存的闭环结果。 [输入及首步核对](heldout_v2_preflight.json) · [推理记录](model_rollout_run.json)
