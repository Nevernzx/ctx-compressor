# §6 可行性试验：无阅读模型部分

固定 seed=20261117；150 个任务，每任务 4 题，共 600 道互不重复的 dev 题；top-20。单次运行，报告点估计及 n，不计算置信区间。
全程纯 CPU、离线；未下载或训练模型，未调用 API。阅读模型 F1 / EM：**未测（需阅读模型）**。以下指标仅描述证据选择及输入成本，证据完整题比例是代理指标，**不是 F1**。
语料库与 BM25 均仅使用 MuSiQue-Ans dev；片段为 `title + "\n" + paragraph_text`，Qwen3 分词器使用 `add_special_tokens=False`。任务索引从 0 开始，检索种子等于任务索引；19 个配置共用每个任务的一份检索步骤。
